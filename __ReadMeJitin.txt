1. SEAMLESS "ENTER-TO-NEXT" BILLING LOOP:
------------------------------------------------------------------------
- Customer Search  -> [Enter] -> Jumps to Product Search
- Product Search   -> [Tab/Down] to select -> [Enter] -> Jumps to Qty (selected)
- Qty              -> Type quantity -> [Enter] -> Jumps to Price
- Price / Rate     -> [Enter] -> Jumps to Discount %
- Discount %       -> Type discount -> [Enter] -> Adds item to bill & focuses back to Product Search!


2. KEYBOARD SHORTCUTS TABLE:
------------------------------------------------------------------------
F1  or Ctrl+C       : Focus Customer Search
F2  or Ctrl+P       : Focus Product Search
F3  or Alt+C        : Quick Add New Customer Popup
F4  or Enter        : Edit Selected Item in cart table (in-place)
Del or Backspace    : Delete Selected Row from cart table
F9  or Ctrl+S       : Save Invoice + Generate PDF Estimate
F12                 : Jump focus directly to Paid Amount
Alt+X               : Clear / New Bill
Tab                 : Move down in search autocomplete suggestions (like Arrow Down)
Shift+Tab           : Move up in search autocomplete suggestions (like Arrow Up)
Esc                 : Dismiss search suggestions dropdown
